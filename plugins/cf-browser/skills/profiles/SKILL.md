# Manage account environments

Read [profile behavior](../browse/references/profiles.md), then discover `advanced topic=profiles` for the exact operation schema.

Inspect metadata first. Use the existing everyday profile for ordinary browsing and parallel tasks. Create another profile only for a user-requested separate account environment. Restore/delete operations require an inactive profile; let its tasks and human control finish first.

A successful management operation reports the changed profile name and metadata. Verify the intended account on a fresh page when restoring or cloning; saved storage alone does not establish that a site still accepts a session.
